<p>AI 서비스 구축을 위한 LLM 프롬프트 엔지니어링 가이드 ## 1. 프롬프트 엔지니어링이란 무엇인가?

프롬프트 엔지니어링(Prompt Engineering)은 대형 언어 모델(LLM)로부터 원하는 최적의 응답을 이끌어내기 위해 입력 텍스트(프롬프트)를 구조화하고 최적화하는 기술이다. 단순히 질문을 던지는 것을 넘어, 모델의 지식 인출 경로를 유도하고 환각(Hallucination) 현상을 최소화하는 핵심 방법론으로 자리 잡았다.

### 주요 구성 요소
효과적인 프롬프트는 일반적으로 다음과 같은 요소들로 구성된다.

| 구성 요소 | 설명 | 예시 |
| :--- | :--- | :--- |
| **역할 (Role)** | LLM에게 부여할 페르소나나 전문가 정의 | "너는 10년 차 시니어 백엔드 개발자야" |
| **맥락 (Context)** | 작업 수행에 필요한 배경 정보나 제약 사항 | "현재 Spring Boot 3.0 환경에서 코드를 작성 중이다." |
| **작업 (Task)** | 모델이 수행해야 할 명확한 지시 사항 | "주어진 SQL 쿼리의 성능을 최적화해줘." |
| **출력 형식 (Format)** | 결과물의 구조나 포맷 지정 | "마크다운 코드 블록과 수정 이유를 요약해서 반환할 것" |

## 2. 기본 프롬프트 기법

### 2.1 제로샷 프롬프트 (Zero-shot Prompting)
별도의 예시를 제공하지 않고, 모델의 사전 학습된 지식에만 의존하여 작업을 수행하게 만드는 방식이다. 간단한 분류나 요약 작업에 적합하다.

```text
다음 리뷰의 감성을 긍정, 부정, 중립 중 하나로 분류해줘.
리뷰: "배송은 빨라서 좋았는데 제품 마감이 조금 아쉽네요."
```

### 2.2 퓨샷 프롬프트 (Few-shot Prompting)
모델에게 원하는 작업의 입력과 출력 예시를 몇 가지(Few) 제공하여, 패턴을 학습하고 정확도를 높이는 기법이다. 복잡한 형식이나 도메인 특화 태스크에서 효과적이다.

```text
[예시]
입력: 사과
출력: 과일

입력: 강아지
출력: 동물

[실제 작업]
입력: 현대자동차
출력:
```
